# 安装与使用

支持 Windows 10/11、Python 3.12+、已安装的 Google Chrome。首次安装依赖需要网络，不需要另外下载 Playwright 浏览器。

1. 将项目解压到固定目录。不要把真实账号文件放进公开仓库。
2. 在 PowerShell 运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\安装依赖.ps1`。
3. 双击 `启动工作台.cmd`，页面地址为 `http://127.0.0.1:5192/`。
4. 不登录也可点击“体验演示数据”。演示使用动态生成的虚拟账户和14维度数据，与本地报表分离。
5. 真实使用时，进入数据管理，保存京准通显示的账户名称和账户ID；不是密码。打开专用Chrome并人工登录，然后进入快车账户报表页。保持这个专用窗口只打开一个目标账户的报表标签。
6. 人工核对账户，选择昨天或更早的采集日期，勾选登录确认，再点击生成下载。固定30天转化／下单／不含赠品／成交订单。
7. 先生成全部报表，再到下载管理逐份下载。完成后自动刷新。可创建桌面快捷方式；项目移动后删除旧快捷方式再创建。

## 采集与恢复

不要同时运行多份项目或多个采集脚本。进程锁会阻止并发采集。中断后原任务和文件保留；恢复时选相同日期和账户。已经完成的文件重新校验后跳过。无法确认提交结果时停止核对，不自动重复提交。

登录失效和验证码由用户处理。若采集已停止，人工处理后再重试原日期；没有绕过验证码的能力。不要随意删除任务目录，否则会失去防重复提交依据。切换账户前先备份并使用独立项目数据目录；当前看板不支持多账户同时管理。

## 数据与口径

账户8维度：账户、计划、单元、创意、关键词、商品定向、人群、流量包。效果6维度：搜索词、地域、商品定向、品类、商品、品牌追击（后台品牌拦截）。不含全站营销和站外广告。

账户报表分日，效果报表为完整周期。效果数据不能拆日；不同表覆盖不一定相等，禁止跨表相加。ROI按归因订单金额/花费重算，不代表利润。跟单SKU是成交商品，缺少计划ID时不归入计划分析。用户去重指标不跨行加总。

今天、昨天等快捷日期按北京时间日历计算，最近N天含今天。看板可以选今天，但当前采集只接受完整历史日；今天缺少完整本地数据时会提示。平台保留期和可下载日期由京东决定，不保证任意历史区间可下载。

## 本地隐私与备份

真实报表和任务在 `data/`，账号配置在 `config.local.json`；Chrome登录环境在系统当前用户本地应用数据目录下 `JdReportDownloader/browser-profile-chrome`。这些不在发布包中。工作台不读取/导出登录凭证，不修改投放，不上传数据；没有钉钉通知功能。

复盘与指标偏好在当前浏览器，清缓存会丢失，复盘请导出JSON备份。报表备份需保存整个data及配置，包含经营信息。服务只绑定127.0.0.1，不支持公网或多人部署。

## 问题排查

- 依赖安装失败：检查Python版本和网络，重新运行安装脚本，失败时不会宣称安装成功。
- 端口5192被其他软件占用：先确认占用程序；不要关闭未知进程。
- Chrome未找到：安装标准位置的Google Chrome。
- 账户核验失败：检查账户ID、专用窗口登录状态和报表页。不要反复扫码或复用普通浏览器凭据。
- 同日期出现其他账户快照：先备份，使用独立项目副本配置另一账户，不覆盖原数据。
- 本地文件哈希或日期不符：停止导入并保留原件，不会静默忽略校验错误。
